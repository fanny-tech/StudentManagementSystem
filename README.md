 Student Management System 

A simple Java application demonstrating core OOP concepts.

 Key Concepts Demonstrated
Classes and Objects :Student class with two objects created in main()
cunstructor : Initialises name, age, and marks when a new student is create
Instance Methods :displayStudentInfo(), calculateGrade(), isPassed(),compareMarks()
Static Method :schoolMotto()` called using the class name: Student.schoolMotto()
Void Methods :displayStudentInfo() and schoolMotto() return nothing
Return Type Methods :calculateGrade() returns a String, isPassed() returns boolean
Instance Variables :name, age, marks belong to each student object
  Local Variables  :bonusMarks declared inside main(),visible only there
Variable Scope: instance variables live with the object; local variables die when method ends
Control Flow : if-else used in calculateGrade() and compareMarks()
